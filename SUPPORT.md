# Support

## Plugin bugs

Use the repository's
[bug report form](https://github.com/superfly/openclaw-sprites/issues/new?template=bug_report.yml)
for reproducible problems with installation, sandboxing, workspace transfer,
sleep/wake behavior, or the plugin CLI.

Include the plugin and OpenClaw versions, Node.js version, Gateway operating
system, relevant redacted output, and the smallest reproduction.

## Product questions

- Plugin setup and troubleshooting: [README](README.md).
- Sprites usage: [Sprites documentation](https://docs.sprites.dev/) and the
  [Fly.io community](https://community.fly.io/).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md).
- Account, billing, or production incidents:
  [Fly.io support options](https://fly.io/docs/about/support/).
